# Known limitations

- The bootstrap shell does not yet open or edit image files.
- Tool buttons and inspector tabs establish the accessible interaction contract, but feature behavior arrives in later gated phases.
- The Phase 2 shell self-hosts IBM Plex Mono and uses the Soft Technical visual system; image editing and document creation remain gated for later phases.
- The Phase 1 browser harness does not select an Object Selection engine. It still needs five approved local photos and a second candidate with a quantized lazy-loaded segmentation model.
- Mobile and tablet layouts are not v1 targets.
